# Origen de las decisiones de Campaign-V2

Material de trabajo del que salieron [DECISIONES-GRILL.md](../DECISIONES-GRILL.md) y [DECISIONES-WAYFINDER.md](../DECISIONES-WAYFINDER.md). Se guarda para conservar el porqué de cada decisión. Las decisiones vigentes son las de esos dos archivos.

- `grill-rondas/`: los HTML de las tres rondas de grill-with-docs.
- `respuestas/`: las respuestas del autor a cada ronda.
- `wayfinder/`: el mapa (`map.md`), los tickets (`issues/`), el grill de cada ticket, las arquitecturas comparadas, el material de Astra, la investigación y el prototipo.
