Lenguaje del programa

El seudocódigo es otra vista del mismo programa: se guarda y se ejecuta como JavaScript. Lo que todavía no tiene seudocódigo se queda en JavaScript. Python es otro lenguaje: al elegirlo, el programa JavaScript se convierte si cabe y se conserva; Python se traduce y corre en el mismo motor.

Edición sin teclado

El botón con el teclado (⌨) cambia entre escribir y editar por bloques. Sin teclado, un toque elige un elemento entero (textos con sus comillas, comentarios completos), el doble toque amplía la selección y arrastrar copia un valor sobre un hueco o mueve líneas.

Modo pantalla completa inactivo

Para tabletas y teléfonos: salta de la batalla al código con un toque. Se activa y se desactiva manteniendo pulsado 2 segundos el botón de las cuatro esquinas.

Arrastra el divisor hasta un extremo para ver solo el mapa o solo el código. Arrástralo de vuelta para recuperar ambos.

También puedes hacer doble clic en el divisor para restaurar el reparto.

Barra de edición

Arrastra un botón para cambiarlo de sitio o llevarlo a otro grupo. Arrastra el asa ⋮⋮ de un grupo para mover el grupo entero. Suelta un botón en «Grupo nuevo» para separarlo.

Modo pantalla completa

Pensado para tabletas y teléfonos: la batalla y el código ocupan, cada uno, toda la pantalla, y se pasa de uno a otro con un toque.

  • Activar o desactivar: mantén pulsado 2 segundos el botón de las cuatro esquinas, arriba a la derecha. El círculo se llena mientras mantienes el dedo. Con el modo activo, el icono brilla en blanco.
  • De la batalla al código: el botón </>, junto a Ajustes, pone el editor a pantalla completa.
  • Del código a la batalla: ▶ EJECUTAR, en lugar de las pestañas de programas, corre el código, muestra la batalla y cierra el inspector si estaba abierto. El botón del mapa, que flota bajo el de pantalla completa, vuelve a la batalla sin ejecutar.
  • Campo girado: con la pantalla en vertical, la batalla se gira 90° para aprovechar el alto: la base queda abajo y los enemigos llegan desde arriba. Al girar el teléfono a horizontal vuelve la vista normal. Cada postura recuerda dónde dejaste la cámara. Se desactiva en Ajustes.
  • El divisor sigue funcionando: arrástralo para ver ambos paneles; los botones vuelven a llevarte a pantalla completa mientras el modo siga activo.

El botón solo aparece en pantallas de tableta o teléfono.
